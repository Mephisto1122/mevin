Camera setup

Connection formats for common camera brands.

Hikvision>

Most common security cameras.

rtsp://admin:PASS@IP:554/Streaming/Channels/102
101=Main102=Sub
Use sub stream (102) for faster results

Dahua / Imou>

Second largest manufacturer.

rtsp://admin:PASS@IP:554/cam/realmonitor?channel=1&subtype=1
subtype=0 Mainsubtype=1 Sub

TP-Link Tapo>

Budget smart cameras.

rtsp://USER:PASS@IP:554/stream2
stream1=HDstream2=SD
Enable RTSP in Tapo app first

Reolink>

Great value NVR cameras.

rtsp://admin:PASS@IP:554/h264Preview_01_sub
_main=HD_sub=SD

Xiaomi / Yi>

Needs custom firmware.

rtsp://IP:8554/unicast
yi-hack
Stock firmware has no RTSP

ONVIF>

Universal, 90% of cameras.

rtsp://admin:PASS@IP:554/onvif1
Profile S
Use ONVIF Device Manager to find URL

Phone Camera>

Android/iOS phone.

http://PHONE_IP:8080/video
